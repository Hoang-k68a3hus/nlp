
# LAB 05 — Sequence Classification

Bài thực hành phân loại cảm xúc trên IMDb bằng TF-IDF + Logistic Regression, RNN, LSTM và GRU.

## Giới thiệu các file

| File | Nội dung |
|---|---|
| `calculations.md` | Bài tập tính toán RNN, LSTM và câu hỏi lý thuyết. |
| `prediction.md` | Năm dự đoán trước khi làm thực nghiệm. |
| `rnn_cell.py` | Tự viết một bước RNN và đối chiếu với PyTorch. |
| `sequence_classification.ipynb` | Tiền xử lý, huấn luyện, so sánh và đánh giá các mô hình. |
| `results.csv` | Bảng kết quả đánh giá mô hình. |
| `learning_curves.png` | Biểu đồ train loss và validation loss. |
| `confusion_matrix.png` | Ma trận nhầm lẫn. |
| `error_analysis.md` | Phân tích ba dự đoán đúng và ba dự đoán sai. |
| `reflection.md` | Tổng kết kiến thức rút ra từ LAB 05. |
